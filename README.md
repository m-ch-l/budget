# Budget

A simple, private budget tracker in a single `index.html` file.

- Type spending in plain words (`14.20 lunch at chipotle`) and it is categorized automatically.
- Monthly category budgets, recurring payments and subscriptions.
- Optional Apple Pay auto-add via an iOS Shortcuts "Transaction" automation (Settings → Pay auto-add).
- All data stays in your browser. Back it up from Settings (saves to iCloud Drive on iPhone).
